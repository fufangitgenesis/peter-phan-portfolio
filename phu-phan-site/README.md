# Phu Phan — portfolio

A static site, ready for GitHub Pages. No build step.

## Deploy
1. Create a new GitHub repository (use `username.github.io` for a root URL).
2. Upload these files to the repository root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. Your site appears at `https://username.github.io/` within a minute or two.

## Edit
Change the text in `index.html` and the colours or fonts in `style.css` (see the variables at the top).
